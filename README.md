# JavaScript Fundamentals Projects

This repository contains projects I'm building to strengthen my understanding of JavaScript fundamentals through hands-on practice. All projects are being developed using **vanilla JavaScript**, along with HTML and CSS, without frameworks or libraries.

## Projects

- **[Musify](https://musify-music-streaming-site.vercel.app/)**: A music streaming website.
- **[Calculator](https://calculator-projects-js.vercel.app/)**: A calculator with basic arithmetic operations and keyboard support.
- **[Calculator](https://projects-js-analog-clock.vercel.app/)**: Analog Clock.

## Goal

My goal is to improve my JavaScript problem-solving skills and build interactive web applications using pure JavaScript, one project at a time.
